# Changelog

## 3.1.0 🎆

This is the first Avakas changelog entry. Avakas can inspect, set, and
automatically bump semantic versions across several project formats while
coordinating the corresponding Git commit and tag workflow.

This release restores and hardens the existing release-intent, prerelease,
container, and publishing paths. See the [README](README.md) for supported
project flavors, commands, and examples.
